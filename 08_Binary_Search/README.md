# Binary Search

This folder starts the binary search section with core search-space ideas.

## Prerequisites

- Finish `05_Arrays/` first.
- You should be comfortable with sorted arrays.
- Learn basic binary search before moving to answer-space binary search problems.

## Study Order

1. `binary_search.cpp`
2. `lower_bound.cpp`
3. `search_insert_position.cpp`

## Notes

- Start with exact-value search.
- Then learn boundary-finding problems like lower bound.
- Then move to variations where the answer is the insertion position.
