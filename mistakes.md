# Mistakes To Watch

- Forgetting the base case in recursion or making it too weak.
- Using the wrong loop bounds and skipping the last element.
- Confusing `<` and `<=` in array and pointer problems.
- Not handling empty arrays or single-element arrays.
- Forgetting to verify an "optimal" candidate answer, like majority element.
- Using sliding window when negative numbers are present and prefix sums are required instead.
- Breaking sorted-array assumptions and still using two pointers.
- Modifying the input array when the problem expects it to stay unchanged.
- Ignoring integer overflow in sum, product, or reverse-number problems.
- Mixing problem-solving code with too much debug output in `main()`.
