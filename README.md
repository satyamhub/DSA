# DSA Study Repository

This repository is now arranged by topic so you can study in a cleaner order.

## Suggested Study Order

1. `01_Basics/`
2. `02_Patterns/`
3. `03_Recursion/`
4. `04_Sorting/`
5. `05_Arrays/`
6. `06_Hashing/`
7. `07_STL/`

## Folder Guide

- `01_Basics/`: arithmetic, number theory basics, and early C practice.
- `02_Patterns/`: star patterns and character drawing practice.
- `03_Recursion/`: one recursion problem per file, from sum/factorial basics to Fibonacci.
- `04_Sorting/`: one sorting algorithm per file, from O(n^2) sorts to merge sort and quick sort.
- `05_Arrays/`: array questions split into `Easy/` and `Medium/`.
- `06_Hashing/`: number hashing and character hashing.
- `07_STL/`: STL practice with `unordered_set`.
- `build/`: compiled output files kept out of the main study path.
- `practice_io/`: input and output helper files.

Start with the README inside each topic folder before opening the code files.

## Revision Helpers

- `practice_sheet.md`: a simple day-by-day revision order.
- `mistakes.md`: a running list of common bugs and habits to watch during practice.
