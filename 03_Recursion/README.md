# Recursion

This folder is now split into one problem per file.

## Prerequisites

- Finish `01_Basics/` first.
- Be comfortable with functions, loops, and basic arrays/strings before recursion.
- Learn basic recursion before moving later to subsequences and backtracking.

Study order:

1. `sum_of_first_n.cpp`
2. `print_1_to_n.cpp`
3. `factorial.cpp`
4. `reverse_array.cpp`
5. `palindrome_check.cpp`
6. `fibonacci.cpp`

## Notes

- Start with parameterized and functional recursion in `sum_of_first_n.cpp` and `factorial.cpp`.
- Move to traversal-style thinking in `print_1_to_n.cpp`.
- Then practice recursion on arrays and strings.
- Finish with `fibonacci.cpp` because it compares brute recursive and iterative optimal thinking.
