# Patterns

Use this folder for loop-building practice and output visualization.

## Prerequisites

- Finish `01_Basics/` first.
- You should be comfortable with `for` loops and nested loops before starting patterns.

- `pattern.cpp`: numbered pattern functions from square and triangle patterns up to mirrored and combined shapes.
- `class2.c`: simple calculator practice in C.
- `hw.c`: custom shape and name drawing using nested loops.

Recommended order: `pattern.cpp` first, then `hw.c`.
