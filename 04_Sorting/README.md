# Sorting

This folder is now split into one algorithm per file.

## Prerequisites

- Finish `01_Basics/` first.
- Basic array traversal should already feel comfortable.
- Arrays are enough to start sorting; recursion helps for `merge_sort.cpp` and `quick_sort.cpp`.

Study order:

1. `selection_sort.cpp`
2. `bubble_sort.cpp`
3. `insertion_sort.cpp`
4. `merge_sort.cpp`
5. `quick_sort.cpp`

## Notes

- The first three are basic O(n^2) sorting algorithms.
- `merge_sort.cpp` gives guaranteed O(n log n) time with extra space.
- `quick_sort.cpp` is usually fast in practice but can degrade to O(n^2) in the worst case.
