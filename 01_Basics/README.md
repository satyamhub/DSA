# Basics

Study these first.

## Prerequisites

- None. This is the starting point for the repository.

- `Arithmetic/arithmetic.cpp`: even/odd, prime checking, optimized `isPrime`, and HCF/GCD.
- `Basic_Maths/BasicMaths.cpp`: reverse number, Armstrong number, and divisor listing.
- `C_Practice/class.c`: beginner C programs such as leap year, percentage, calculator, factorial, Fibonacci, and basic formulas.
